# opam-workerd

The opam package `workerd`. It installs the prebuilt [workerd](https://github.com/cloudflare/workerd) binary from Cloudflare.

## Install

```sh
opam install workerd
workerd --version
```

The package version is the version of the npm package `workerd`, for example `1.20261019.1`.
